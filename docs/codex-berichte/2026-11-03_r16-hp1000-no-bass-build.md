# R16 experimental CLP HP1=1000 Hz, no parallel bass — build and validation report

Date: 2026-11-03 (Europe/Vienna). Execution: normal ChatGPT CHAT with GitHub connector and GitHub Actions. This is an **owner-authorized, isolated firmware audition image**, not a production GitHub release, source merge, device flash, or device test. No Codex or Work job was started.

## Owner listening and design decision

The owner extensively tested R14 on real LXR-02 hardware (six FX-routed voice combinations and many CLP controls) and accepted the shared MAX-feedback behavior. Subsequently, the owner auditioned R15 (HP1=110 Hz and no R7 parallel bass): its bass was fully retained and the resulting voicing was promising, but feedback became more step-like in fader and control response; the earlier high-pitched scream became a lower-frequency feedback sound. The owner explicitly requested **the next 1000-Hz HP1 test image**, intending to find a musical compromise rather than preserve R14 timbre. Whether the original 7200-Hz coefficient originated from a calculation error or an intentional experiment remains unknown; the original `7.2Hz` comment alone does not settle intent.

## Scope and deliberate production changes

1. `Core/Src/Soundengine/DSPAudio/FX/Distortion.c`: Change only the HP1 matched-pole coefficient definition from **`0.015536190543605555`** (110 Hz) to **`0.13267953435832913`** (1000 Hz), where `a=1-exp(-2*pi*f/44140)`. Update the nearby explanatory comments accordingly. The three existing HP1 callsites (stereo left/right and mono) retain the same code paths and reference the constant; no new filter or state was introduced.
2. `Core/Src/main.c`: Change only boot identifier from `LXR LAB R15` to `LXR LAB R16`.

The R15 **complete absence of the R7 parallel bass filter and state remains unchanged**. The 0.22 core input trim remains. Original additional 60-Hz HP3, distortion/diode stages, output dry/wet, R5 input-loss feedback gate/reset/diode protection, R14 six-voice MAX selector, R13 block ramp, fader smoothers, FX routing and all unrelated effects are untouched. No individual voice bus instances, output feedback-volume fade, bass recovery path, new UI control, logging, preset change, audio buffer or global gain alteration were introduced.

The owner previously approved eventual investigation of audible solo feedback attenuation, but that is deliberately **not included** in R16. Dense six-voice overload remains deferred.

**Hardware safety/acceptance boundaries:** No device flash, recording, listening, instrument timing or thermal/speaker measurements. CPU cycles, peak ISR latency, stack high-water, actual audio deadline and 1–2-second feedback tails are **UNMEASURED**. R14/R15 device observations are separate and do not certify R16.
