## Owner listening context

- R14: extensively played on the LXR-02 hardware; its shared six-voice MAX feedback felt musical and robust. Still had audible kick-bass loss over part of dry/wet travel.
- R15 (HP1=110 Hz, no R7 parallel bass): owner reported complete bass retention and dramatically altered, lower-frequency feedback, but more step-like control changes.
- R16 (HP1=1000 Hz, no parallel bass): owner reported more room for adjusting CLP parameters, but some feedback changes still felt step-like.
- The owner explicitly requested **the next 3000-Hz audition**. The intention is to compare evolving timbre and continuity, not to force preservation of R14 sound. The origin of the original 7200-Hz HP1 coefficient is undetermined: the 7.2-Hz comment may reflect a calculation error or an intentional later voicing experiment.

## Production change and exclusions

1. `Core/Src/Soundengine/DSPAudio/FX/Distortion.c`: changed **only** `CLIP_HP1_ALPHA` and its nearby explanatory comments. The matched-pole coefficient changes from `0.13267953435832913` (1000 Hz) to `0.34756269835583342` (3000 Hz), calculated by `a = 1 - exp(-2*pi*3000/44140)`. This is the HP1 filter shared by incoming excitation and the regenerative return. No filter topology or extra state was introduced.
2. `Core/Src/main.c`: changed boot identification from `LXR LAB R16` to `LXR LAB R17`.
3. New branch-only evidence/build machinery: `tests/fx_clip_r17/compare.py`, `tests/fx_clip_r17/package.py`, `.github/workflows/clp-r17-build.yml`.

Unmodified: removal of the R7 parallel bass branch and its 16-byte state (R15), input trim `0.22`, R5 linked no-input gate, deferred reset and diode table bound fix, HP3 and other CLP nonlinear filters, original dry/wet interpolation, the R14 six-voice MAX feedback selection and block interpolation, individual voice fader smoothing, output routing and other FX, and serialization/preset formats. Previously approved *future* audible feedback output gain adjustment is not present; dense six-voice input overload remains deliberately outside scope.

The R17 workflow compares the production `Distortion.c` and `main.c` **byte for byte** against exactly pinned R16 base with only the expected coefficient/comment and splash substitutions. It separately byte-compares R14 mixer/FX-bus/voice/fader code at its pinned source. The GitHub R16→R17 comparison confirms only the five listed changed/added files.
